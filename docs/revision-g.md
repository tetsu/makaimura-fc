# 国内版 Revision G の挙動調査

対象は `makaimurg`、MAME 0.289、既定 DIP、コールドブート後の最初の無入力デモ。MAME の ROM 照合結果は `romset makaimurg [gng] is good`。REA の ZIP 調査で得た SHA-256 は `d2a4f9e0f7139307be51371268d7ce367bf8fd9179ca188991c35ed9dee596bc`（Evidence `ev_b09fd6582bf439d008a8f42a3b19ba6d90c7226001ced8786e10db67e1eda0e8`）。以下の動作測定は MAME で行った。

## 再現方法

リポジトリのルートから次を実行する。番号は Lua のフレーム通知を 1 から数えた値で、描画済み画像にはバッファリングによる時間差があり得る。MAME の画面更新は 59.637405 Hz。同じ条件で2回起動し、4種類の観測ログが一致した。

```powershell
mame makaimurg -rompath reference -noreadconfig -video none -sound none -nothrottle -skip_gameinfo -autoboot_delay 0 -autoboot_script tools/mame/measure-revg.lua
```

[計測スクリプト](../tools/mame/measure-revg.lua)は `motion` にフレーム、横スクロール値、表示部品の左端 X と上端 Y、部品数、作業 RAM の縦座標候補を出力する。`write_y` は縦座標への書き込み、`background` は背景 RAM の列と更新行のビットマスクを示す。書き込みの番号は直前のフレーム通知を指す。部品を選ぶ条件はこの短い区間に合わせたもので、別の姿勢・敵・面には再検証が必要。

## 動きと地形接触

| 観測フレーム | スクロール X | 表示左端 X | 表示上端 Y | RAM $050A |
| --- | ---: | ---: | ---: | ---: |
| 1261 | 82 | 112 | 178 | 62 |
| 1278 | 98 | 112 | 138 | 102 |
| 1291 | 114 | 112 | 159 | 81 |
| 1318 | 141 | 112 | 178 | 62 |

- **横移動とカメラ。** フレーム1165から1185までに左端 X が89から110へ移り、横スクロール値は0のままだった。1190から1260までは左端 X が112付近に留まり、横スクロール値が2から81へ進んだ。この区間の地形に対する平均移動量は約1.13 px/フレーム。歩行とカメラ追従は別々に比較する。
- **上昇と着地。** この動作の表示上端は178から138まで40 px 上昇し、1291〜1314の24サンプルで159を保ち、1318で178に戻った。平地より19 px 高い位置にいったん乗った動きと整合する。この1回から平地間の滞空時間や全ジャンプ共通の高さは決められない。
- **縦座標補正。** 通知1291の後、作業 RAM `$050A` に78を書いた後で81を再度書く動作を観測した。書き込み時に報告された 6809 の PC は順に `$94C3` と `$9E84`。後者が地形の高さへ座標を戻す処理の候補。これは敵との接触矩形や足元の検査点を確定する証拠ではない。
- **接触時の比較。** 日本版 G の固定 ROM を MAME 同梱の `unidasm` で調べると、`$9E52–$9E66` では2つの差にオフセットを加え、どちらかが符号なし上限を超えると次の候補へ進む。縦座標の書き戻し命令は `$9E82` で、タップが報告する `$9E84` はその直後。ログの `contact` はフレーム、X・U レジスタ、比較に使う4バイトの順。1291と1292では X=`$0510`、U=`$1390`、値は順に12・24・19・38だった。対象との相対距離を2軸で検査する処理と解釈できる。立ち・しゃがみ・敵弾への適用範囲は未確認。

## ステージと背景更新

観測区間1190〜1329では、背景 RAM の列17から25までを計9回、毎回32行ずつ更新した。更新間隔は12〜18フレーム。この結果は、FC側で横スクロール時に列転送が集中する試験を組む根拠になる。ここでの列番号は循環する表示用 RAM の位置で、ステージ全体の長さや地形判定の配列位置は別途調べる。[MAME の背景タイルと描画の定義](https://github.com/mamedev/mame/blob/master/src/mame/capcom/gng.cpp)

## 次の比較実験

1. **プレイヤーと敵の動き。** 同じ開始状態から無入力・歩行・停止・垂直ジャンプ・前進ジャンプを比較する。押下・解放時刻、ワールド座標、頂点、着地を記録する。敵は出現・接近・攻撃の各状態を区切って追う。
2. **当たり判定。** 同じ足場の端で開始位置を1 pxずつ変え、接地する最後の位置と落下する最初の位置を対にする。敵本体と弾は別々に、立ち・しゃがみ・空中で命中と空振りの境界を測る。表示上の重なりと被弾フラグの変化を照合する。
3. **レベルデザインと各面。** 面と復帰地点ごとに観察区間を識別し、足場間の距離とジャンプ到達距離の比、カメラが止まる位置、敵の出現条件、死亡後の復帰条件を記録する。進入速度を変えて位置依存と時間依存を切り分ける。今回の測定範囲は冒頭デモの一部で、各面の構造と出現条件は未測定。
