# 国内版 Revision G の区間0の敵の動作

区間0に出る敵の種別（`$00`、`$01`、`$03`、`$05`、`$07`、`$08`、`$0B`、`$11`）について、状態の流れ、速さ、耐久値、得点、当たり判定をまとめた。内容は逆アセンブルから読み、主な値は MAME で確かめた。魔術師（`$07`）は [魔術師](revision-g-stage-data.md#魔術師種別-07) にある。種別の名前と更新処理の番地は [敵の出現](revision-g-stage-data.md#敵の出現) の表による。

表記は次のとおり。

- 枠の基準を X とし、オフセットは X からの値で書く。状態語は `−$0D`（上位）と `−$0C`（下位）、段階は `−$0B`。表の「状態」欄の `$0101.2` は状態 `$0101` の段階2を表す。
- 位置は X が `−$0A`、Y が `−$07` の語。Y は上が正。
- 速さは1フレームあたりの px。8.8 固定小数の値を10進に直した。
- `<$9A` は難易度。`<$9A & $30` で選ぶ4行の表が多く、ここでは「難易度の行0〜3」と書く。既定の DIP は行0。
- `<$21` はフレームカウンタ、`<$E0` は敵の更新ループ（`$9F0C`）の残り枠数（40〜1）。2つを足した値は、枠ごとにずれる疑似乱数として使われる。乱数の処理は `$68F9`（`$6E/$6F` の16ビット LFSR）。
- 敵の更新ループは bank4 を選んでいるので、表の番地 `$4000–$5FFF` は bank4 の番地。

## 共通の表

### 自弾との当たり

`$EEA6–$EF78` が、敵40枠と自弾4枠（`$0540` から `$40` 刻み）の組を調べる。

| 表 | 内容 |
| --- | --- |
| `$EF92` → `$EF9C + 8 × 種別` | 当たり枠。武器0〜4は同じ表を使う。［X の補正、X の幅、Y の補正、Y の幅］で、差 + 補正が幅以下なら当たる。 |
| `$EE89[$73]`、`$EE91[種別]` | 武器のビットと、種別ごとに効く武器のマスク。`$0D`（アスタロト）は武器3だけ、`$0E` はどの武器も効かない。ほかは武器0〜4が効く。 |
| `$EF7A[種別]` | 耐久値のオフセット。0は1発で倒れる。命中すると `−$0E` に1を書き、耐久値を1減らす。 |
| `$F034[種別]` | 倒したときの得点の番号。`$EF37` がタスク `$0C` で bank3:`$542F` に渡す。 |
| `$F047[$73]` | 1なら命中した自弾を消す。0の武器（2）は貫通し、敵ごとの当たり済みビットだけを消す。 |

`−$10` のビット7が立っている敵には効かず、自弾は状態 `$0203` ではね返される（フライングナイトの盾）。

| 種別 | 名前 | 自弾との当たり（X、Y） | 耐久値 | 得点 |
| --- | --- | --- | --- | --- |
| `$00` | ウッディピッグ？ | ±12、±16 | 1 | 100 |
| `$01` | カラス | ±12、Y −16〜+8 | 1 | 100 |
| `$03` | フライングナイト | ±12、±16 | 1 | 100 |
| `$05` | レッドアリーマー | ±10、±13 | 3（`+$1E`） | 1,000 |
| `$07` | 魔術師 | ±12、±13 | 1 | 2,000 |
| `$08` | ユニコーン | ±16、±21 | 10（`+$16`） | 2,000 |
| `$0B` | ゾンビ | ±12、Y −18〜+10 | 1 | 200 |
| `$11` | 食人植物 | ±12、±16 | 1 | 100 |

Y の範囲は「敵の Y − 自弾の Y」。カラス（補正16、幅24）とゾンビ（補正18、幅28）は上下で幅が違う。

### プレイヤーとの当たり

`$F057–$F0B3` は、`$AD`（無敵の残り）が0のとき、敵40枠とプレイヤーの重なりを調べる。表は `$F0B4[−$01]` が指す。`−$01` が10の敵だけ `$F1FA` を使い、ほかは `$F0CA` を使う。しゃがんでいる（`$051F` が0でない）ときは、それぞれ `+$98` の表を使う。重なると、プレイヤーは状態 `$0300`（被弾）になる。

| 種別 | 立っているとき（X、Y） | しゃがんでいるとき（X、Y） |
| --- | --- | --- |
| `$00` | ±14、±14 | ±15、−15〜+9 |
| `$01` | ±10、±8 | ±11、−9〜+3 |
| `$03` | ±10、±20 | ±11、−21〜+15 |
| `$05` | ±16、±19 | ±17、−19〜+13 |
| `$07` | ±30、±30 | ±31、−31〜+25 |
| `$08` | ±23、±30 | ±24、−31〜+25 |
| `$0B` | ±9、±19 | ±9、−19〜+13 |
| `$11` | ±10、±14 | ±10、−14〜+8 |

Y の範囲は「敵の Y − プレイヤーの Y」。しゃがむと上側が6 px 狭くなる。

敵弾は `$F48C–$F4FD` が6枠（`$13D0` から `$20` 刻み）を調べる。表は `$F4FE + 8 × 弾の種別`、しゃがんでいるときは `+$80`。種別0（魔術師の呪文）に触れると変身（状態 `$0400`）、ほかは被弾になる。弾に触れた後、その弾は状態 `$0200` になる。

### 枠の回収と撃破

- `$8DC5` は、X がカメラ X −128〜+383、Y がカメラ Y −64〜+319 の外に出た敵を状態 `$0300` にする。
- 撃破の状態 `$0200` では、どの種別もまず効果音（`$14` か `$1B`）を送る。続いて共通の爆発の処理（`$E7A3` は18フレーム、`$E7CE` は36フレーム）に入り、`$0300` で枠を返す。
- `$0300` は多くの種別で、残り数 `$0030 + 種別` を1戻す。食人植物は戻さない。
- 落とし物は種別の処理にはなく、出現の6回に1回付く共通の仕組み（`$EB02–$EB31`）による。

## ウッディピッグ？（種別 `$00`）

| 状態 | 処理 |
| --- | --- |
| `$0000`（`$9F5F`） | `−$10` を2（当たらない）、絵を空の `$A4AB` にする。宙返りの残り回数 `+$06` を (`<$21` + `<$E0`) & 7 にする。プレイヤーのいる側を向き、速さの表を選ぶ（下の表）。状態を `$0001` + バリアントにする。 |
| `$0001`（`$9FB3`） | バリアント0。画面上の X が16〜240の外にいる間は、毎フレーム2回動く。画面に入ると `$0100`。 |
| `$0002`（`$9FE5`） | バリアント1・2。動かずに、4コマ × 12フレームの目の演出（台本 `$4738`、`$4749`）をしてから `$0100`。 |
| `$0100`（`$A045`） | 最初のフレームに `−$10` を1にする。横に飛び、128フレームに1回効果音 `$19`。16フレームに1回、宙返りと発射の判定をする（下）。 |
| `$0101`（`$A0B8`） | 宙返り。8回に分けて方向を1つずつ変え、180°回る。回る間隔は `<$E0` のビット0で、計31フレームか計50フレーム。画面の向こう半分へ向かっているときはもう1回回る。 |
| `$0102`（`$A16C`） | 発射。止まってプレイヤーの方を向き、`$A19E[$9A >> 3]`（26〜6）フレーム待つ。弾を放してさらに10フレーム待ち、`$0100` に戻る。 |
| `$0200`（`$A267`） | 放す前の弾を消し、効果音 `$1B`。`$E7CE` の36フレーム。 |

- **速さ。** 真横の速さは難易度の行で選ぶ。行0は1.55、行1は1.80、行2は2.0、行3は2.25。4体に1体（(`<$E0` + `<$21`) & 3 = 0）は速い表を使い、行0〜2は2.25、行3は2.63 になる。斜めと縦の方向は、どの表でも1.55。方向は16通り。
- **宙返りの判定（`$A07D`）。** プレイヤーとの横の距離で決まる値を `+$08` に足し、桁があふれたら宙返りする。足す値は、距離0〜31で `$4C`、32〜63で `$50`、64〜95で `$26`、96〜127で `$19`、128以上で0。回る向きはプレイヤーとの高さの差で決まる。敵がプレイヤーより32〜64 px 上なら下回り（急降下）、32 px より下なら上回り。64 px より上なら約15%で上回りになる。
- **発射の判定（`$A1F9`）。** 次の3つがそろうと撃つ。プレイヤーとの横の距離が16 px を超える。敵がプレイヤーより上にいる。使用中の敵弾の数が上限 `$A22A[$9A >> 4]`（1、2、4、5）より少ない。
- **弾（種別4）。** 放すまでは毎フレーム狙い直す。放した後は、横の距離が縦以上なら横に、そうでなければ縦に、約2.27 px で飛ぶ。地形に当たるか画面外に出ると消える。

計測では、区間0のページ9から始めた試行で、バリアント1（目の演出48フレーム）とバリアント0の両方が出た。ドキュメントの種別の表では、バリアント1は区間2・4・5だけとしていたが、区間0にも出る。発射前の弾は16フレームの間動かなかった。

## カラス（種別 `$01`）

区間0の開始時の表に5羽あり、どれもバリアント5（墓石に止まる青いカラス）。

| 状態 | 処理 |
| --- | --- |
| `$0000`（`$A2D4`） | 止まる時間の表を `$4B84[$9A >> 4]` から選ぶ。揺れの基準 Y を今の Y、振幅を16にする。速さの表を `$4B1C`（±1.25）にして `$0100`。 |
| `$0100.0`（`$A5E5`） | 画面に入る（`−$0F` が立つ）まで待つ。入ったら、止まる時間 `+$0F` を表から乱数で選ぶ。 |
| `$0100.1`（`$A5EF`） | 姿勢の絵を乱数で選び、保つ時間 `+$0E` を55〜75フレームから選ぶ。 |
| `$0100.2`（`$A61F`） | プレイヤーの方を向く。向きが変わるか `+$0E` が切れると段階1に戻る。64フレームに1回効果音 `$24`。`+$0F` を1減らし、0になると `$0101`。 |
| `$0101`（`$A6C3`） | 向いている方へ横に1.25 px で飛びながら、上下に揺れる。向きは変えない。画面外で回収される。 |
| `$0200`（`$A6F5`） | 効果音 `$14`。`$E7A3` の18フレーム。 |

- **止まる時間。** 段階2で数えるフレーム数。難易度の行0では 80、180、125、160、60、10、110、165 から選ぶ。行3では 20〜53 と短い。
- **揺れ。** 基準 Y ± 振幅 × sin（bank4:`$4140` の半周期の表）。半周期は約21フレームで、半周期ごとに振幅を `$4B64` の16個の値（2〜20 px）から替える。最初は上へ16 px。
- 弾は撃たない。

計測では、X 752 のカラスが画面に入ってから段階2で計127フレーム数え（行0の125に近い）、飛び立った。X 864 のカラスは112フレームで138 px 進み、1.23 px だった。

ほかのバリアントは区間0には出ない。バリアント0・4は画面外から2倍の速さで入ってくる。バリアント2（洞窟のコウモリ）は約43フレームかけて降りてから揺れて飛ぶ。バリアント3（窓の赤い鳥）はプレイヤーの方へ1.70 px で真っすぐ飛ぶ。

## フライングナイト（種別 `$03`）

| 状態 | 処理 |
| --- | --- |
| `$0000`（`$AE86`） | 速さの表を `$AEC9[行]` から選び、`$0100`。 |
| `$0100.0`（`$AF09`） | 振幅を50、基準 Y を今の Y、`−$10` を `$81`（盾）にする。乱数で `$0101` か `$0102` を選ぶ。 |
| `$0101`（`$AF2D`） | 左へ進み、Y = 基準 + sin × 50 の弧を43フレームかけて描く。終わると `$0102`。 |
| `$0102`（`$AF75`） | 同じく左へ進み、基準から下に弧を描く。43フレームで `$0101`。 |
| `$0200`（`$AF91`） | 効果音 `$1B`。`$E7CE` の36フレーム。 |

- **速さ。** 横は常に左向きで、難易度の行0から順に1.06、1.31、1.56、1.94。上下は1往復86フレームで、基準から上下に最大約49 px。
- **効果音。** 32フレームに1回 `$1F`。
- **盾。** 自分の X がプレイヤーの X 以上の間、`−$10` のビット7を立てたままにする（`$AF47–$AF5A`）。この間は自弾が効かず、自弾は状態 `$0203` ではね返される。プレイヤーより左に回ると、ビット7を下ろして1発で倒れるようになる。自弾の向きは見ていない。

計測では、状態 `$0101` と `$0102` を43フレームずつ交互に繰り返し、43フレームで X が46 px 減った（1.07 px）。

## レッドアリーマー（種別 `$05`）

| `$0001`（`$B4F7`） | 眠っている。プレイヤーが X ±96、Y ±48 に入ると16フレーム数えて `$0003`。眠っている間に撃たれても起きる。 |

| `$0003`（`$B5AE`） | 耐久値 `+$1E` を3にする。`<$B5` を1増やす（小型の敵の新規登録を止める）。各タイマーを難易度の表から読み、`$0100`。 |
| `$0100.0`（`$B67C`） | 歩く。0.80 px で、台本 `$4C23`（向きとフレーム数の組16個）に従って左右に歩く。下のタイマーと判定で次の段階へ進む。 |
| `$0100.1`（`$B876`） | 飛ぶ。21フレームで56〜88 px（乱数）上がり、プレイヤーの方へ1.75 px（段階の高さ1では2.0）で飛ぶ。プレイヤーを80 px 越えたら5フレーム待ち、16フレームで降りる。 |

| `$0100.3`（`$BA1F`） | 間合いを取る。プレイヤーとの距離が80 px 以内なら離れ、それより遠ければ近づく。2.13 px（2.25）で、7〜27フレーム（乱数）。 |
| `$0100.4`（`$BA9A`） | 段階の高さを1に上げる。40 + 40フレーム点滅する（当たらない）。 |

| `$0200` | 効果音 `$1B`。`$E7CE` の36フレーム、得点の絵 `$E878` を63フレーム。`$0300` で `<$B5` を1減らす。 |

歩いている間（段階0）は、次の判定を順に行う。

| 判定 | 内容 |
| --- | --- |
| 発射（`$B7B0`） | タイマー `+$06` が0になると段階2。難易度の行0では、90、100、220、130、160、180、200、120 フレームの順。 |
| 突進（`$B7D1`） | `+$07` が0になると段階6。72、136、85、92、108、144、70、49 フレームの順。 |
| 飛ぶ（`$B7EF`） | 8フレームに1回 `+$08` を減らし、0で段階1。行0・1では 10、20、30、40、50、60 回の順。 |
| 距離（`$B841`） | プレイヤーとの距離が帯（行0・段階の高さ0で48〜112 px）の外なら段階3。 |
| よける（`$B6E9`） | プレイヤーから離れていて、自分の高さに近い自弾が自分の側にあれば段階5。 |
| 段階を上げる（`$B861`） | 段階の高さ0の間、32フレームに1回 `+$09` を減らす。行0では1,600フレームで段階4。 |

- **弾（種別7）。** 出した時にプレイヤーへの向きを16方向から選び、約2.26 px で真っすぐ飛ぶ（bank4:`$5F79`）。
- **命中しても倒れないとき。** 5フレーム被弾の絵を出し、効果音 `$1A` を送る。その間は横に動かない。無敵の時間はない。
- **回収。** 画面外の判定は Y だけ。横に離れても消えない。

計測では、プレイヤーが X 1376（96 px 手前）に来たフレームに状態 `$0001` の段階2へ進み、16フレーム後の `$0003` で耐久値が3になった。横の移動は、間合いの段階3が7フレームで15 px（2.14 px）、飛ぶ段階1が94フレームで164 px（1.74 px）、突進の段階6が16フレームで34 px（2.13 px）だった。弾は16フレームで36 px 進んだ（2.25 px）。

| `$0105`（`$CA99`） | 撃つ。25フレーム構えてから、向いている方へ種別1の弾を1発、3.0 px で水平に撃つ。 |
| `$0200` | 効果音 `$0F`。爆発21フレーム、得点の絵 `$E87C` を63フレーム。 |
| `$0300`（`$CB0D`） | `<$B5` を1減らし、区間5以外では `$E78C` でボスの残数 `<$B6` を1減らす。0になると鍵の出現待ちに入る。 |

- **攻撃の間隔。** `+$17` が切れると構えに入る。構えの絵で40フレーム歩き、`$0105` で撃つ。間隔の表は難易度の行0・1で22〜94フレーム、行2・3で12〜62フレーム。
- **よける跳び。** 前から56 px 以内に自弾が来ると `$0102` に入る（`$CA24`）。
- **区間による違い。** 区間0には左の端がなく、右の端はカメラ X 上限 + 224。区間5のバリアント2は X 7576〜7752 の間だけを動き、後ろへは跳ばない。

計測では、区間0のページ `$0B` から始めた。画面に入るまでの `$0001` が165フレーム、接地と起動待ちの `$0100` が48フレームだった。跳躍は上りの16フレームで58 px、続く10フレームで6 px 上がり、21フレームで64 px 降りた。突進は56フレームで101 px（1.80 px）、構えから弾まで25フレーム、弾は16フレームで48 px（3.0 px）だった。

## ゾンビ（種別 `$0B`）

既存の計測（[先頭のゾンビの出現](revision-g-rom-map.md#先頭のゾンビの出現)、[プレイ中の難易度とゾンビの速度](revision-g-rom-map.md#プレイ中の難易度とゾンビの速度)）に、状態の流れを加えた。

| 状態 | 処理 |
| --- | --- |
| `$0000.0`（`$D24B`） | `−$10` を2（当たらない）、絵を空にする。 |
| `$0000.1`（`$D25A`） | プレイヤーの Y から、毎フレーム Y を2下げて地面まで降ろす。バリアント1はここで `$0100` に進む。バリアント0は地中の待ちを `$D28B` の16個の値（12〜187）から選び、歩く時間 `+$0A` を180にする。 |
| `$0000.2`、`.3` | 地中で待ってから、プレイヤーの方を向く。 |
| `$0001` | 地面がなければ `$0300`。あれば効果音 `$17` を送り、地面から出てくる（約87フレーム）。 |
| `$0100.0`（`$D32F`） | `−$10` を1にし、プレイヤーの方を向いて歩き出す。プレイヤーを越えた後に歩く時間 `+$07` を `$D372` の8個の値（40〜110）から選ぶ。 |
| `$0100.1`（`$D37A`） | 歩く（速さは既存の計測のとおり、行0で約0.81 px）。プレイヤーの X を越えると段階2。2フレームに1回 `+$0A` を減らし、0になるか足場が切れると `$0101`。 |
| `$0100.2`（`$D3C2`） | 向きを変えずに `+$07` フレーム歩き、`$0101`。 |
| `$0101`（`$D3F7`） | `−$10` を2にして沈む（約36フレーム）。`$0300` で枠を返す。 |
| `$0200`（`$D439`） | 効果音 `$1B`。`$E7A3` の18フレーム。 |

- **バリアントの違い。** バリアント1は地中で待たず、地面から出る動作も効果音 `$17` もなく、すぐ歩き出す。歩く時間 `+$0A` を初期化しないので、前にその枠を使った敵の値が残る。区間0でも、パターン0の5件のうち4件がバリアント1で、計測でもバリアント0と1が混ざって出た。
- 当たらない間（`−$10` が2）は、地中、出てくる途中、沈む途中。

計測（その場に立つ試行）では、地面から出る段階 `$0001.1` が87フレーム、沈む `$0101.1` が36フレーム、バリアント0がプレイヤーを越えずに歩いた時間が360フレームだった。

## 食人植物（種別 `$11`）

既存の計測（[植物型の敵の初弾](revision-g.md#植物型の敵の初弾)）に、状態の流れを加えた。

| 状態 | 処理 |
| --- | --- |
| `$0000`（`$DE13`） | プレイヤーの方を向く。撃つ間隔の列を `$571B[行]` で選び、最初の値を `+$06` に置く。 |
| `$0100`（`$DE52`） | 範囲（カメラ X が X −264〜X +8、カメラ Y が Y −240〜Y）に入るまで待つ。 |
| `$0101`（`$DE65`） | プレイヤーの方を向き、`+$06` を数える。範囲の外に出ると `$0100` に戻り、残りは保つ。 |
| `$0102`（`$DEAD`） | 口を開けて24フレーム後、敵弾に空きがあれば (X −1, Y +5) に種別6の弾を出し、次の間隔を読んで `$0101`。空きがなければ約255フレーム後にもう一度試す。 |
| `$0200`（`$DEF3`） | 効果音 `$1B`。`$E7CE` の36フレーム。`$0300` で枠を返すが、残り数は戻さない。 |

- **撃つ間隔。** 待ち + 約26フレーム。難易度の行0の待ちは 65、70、8、80、8、55、60、85、80、90、33、73、75、90、45、9、79、29、80、45、53 の順に繰り返す。
- **弾（種別6）。** 出した時にプレイヤーへの向きを16方向から選び、約2.26 px で真っすぐ飛ぶ。地形では消えず、画面外で消える。
- 画面外の回収（`$8DC5`）は呼ばない。

計測では、X 816 の個体の1発目から2発目までが94フレーム（待ち70 + 24）だった。

## 計測

`tools/mame/trace-revg-enemy-states.lua` は、区間を選んで始め、プレイヤーを `$AD` で無敵にして右へ歩かせる（64フレームごとにジャンプ）。敵の状態と段階が変わるたびに、その前の状態にいたフレーム数と移動量を出力する。敵弾は出てから16フレームの移動量を出す。`REVG_STATES_STILL=1` でその場に立ち、`REVG_STATES_FIRE=1` で撃つ。`REVG_STATES_TYPES` で種別を絞れる。

区間0の開始地点から歩く試行とその場に立つ試行、ページ `7`、`9`、`B` から歩く試行を、それぞれ3,600フレームと2,400フレーム行った。歩く試行では、プレイヤーは X 1689 や X 1968 付近の水場で落ち、途中復帰した。

```powershell
$mameDir = "$env:USERPROFILE/tools/mame/mame0289"
$env:REVG_STATES_PAGE = 'b'
$env:REVG_STATES_FRAMES = '2400'
& "$mameDir/mame.exe" makaimurg -rompath reference -noreadconfig -video none -sound none -nothrottle -skip_gameinfo -autoboot_delay 0 -autoboot_script tools/mame/trace-revg-enemy-states.lua -cfg_directory build/revg-states/cfg -nvram_directory build/revg-states/nvram
Remove-Item Env:REVG_STATES_PAGE, Env:REVG_STATES_FRAMES
```
