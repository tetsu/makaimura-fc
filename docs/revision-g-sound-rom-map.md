# 国内版 Revision G の Z80 サウンド ROM マップ

対象は MAME 0.289 の `makaimurg` の `audiocpu`（Z80、3 MHz）。プログラムは `gg2.bin`（32 KiB）で、バンク切り替えなしに `$0000–$7FFF` に見える。メイン CPU 側は [6809 ROM マップ](revision-g-rom-map.md)を参照。

## メモリ配置

| CPU アドレス | 内容 |
| --- | --- |
| `$0000–$56C7` | プログラムとデータ。 |
| `$56C8–$7FFF` | `$FF` の埋め草（10,552バイト）。 |
| `$C000–$C7FF` | RAM。リセット処理が全域を0にし、スタックポインタを `$C800` に置く。 |
| `$C800` | メイン CPU からのサウンドコマンド（読み出し）。 |
| `$E000`／`$E001` | 1個目の YM2203 のアドレス／データ。 |
| `$E002`／`$E003` | 2個目の YM2203 のアドレス／データ。 |

[MAME のサウンド側メモリマップ](https://github.com/mamedev/mame/blob/mame0289/src/mame/capcom/gng.cpp)

## 起動と割り込み

| 起点 | 種別 | 確認した内容 |
| --- | --- | --- |
| `$0000` | コード | `IM 1` を設定して `$00E5` へ跳ぶ。`$00E5` は待ちループの後に RAM を消去し、両方の YM2203 のレジスタ `$2D`、`$2E` を選択してから `EI` と `JR` の待機ループ（`$010B`）に入る。 |
| `$0018`、`$0020`、`$0028` | コード | 表引き用の RST。`$18` は `HL += A`、`$20` は `A = (HL + A)`、`$28` は `A` を2倍して `DE` に語を読む。 |
| `$0030` | コード | 分岐表による跳躍。`RST $30` の直後に置いた語の表を `A` で引いて跳ぶ。呼び出し元へは戻らない。 |
| `$0038` | コード | IRQ の入口。`$00D4` でカウンタ `$C000` を進め、`$010E`（コマンド受付）、`$031A`（曲の更新）、`$0620`、`$0A68`（効果音の更新）を順に呼ぶ。 |
| `$003C–$00D0` | データ | 作者の署名の ASCII 文字列。NMI の入口 `$0066` はこの文字列の中にあり、コードはない。 |

処理の主体は IRQ で、主ループは待機だけを行う。

## コマンドの受付

`$010E` は `$C800` を読み、前回値 `$C001` と同じか `$FF` なら何もしない。それ以外は下位6ビットを `RST $30` に渡し、`$0120–$019F` の64語の表で分岐する。

| コマンド | 分岐先 | 処理 |
| --- | --- | --- |
| `$00`、`$09`、`$0A`、`$15`、`$16` | `$01A0` | `$C500` と `$C620` から `$20` バイト間隔で各5個の先頭バイトを0にする（効果音の停止）。 |
| `$01–$08`、`$0B–$14`、`$17`、`$19–$1B`、`$1E–$24`（29個） | `$0926–$0A3E` | 効果音。10バイトのスタブが `IX` にチャンネル領域、`HL` にデータの先頭を入れて `$0A48` へ跳ぶ。 |
| `$18`、`$1C`、`$1D`、`$25–$3F`（30個） | `$0FD5–$3CF5` | 曲。9バイトのスタブが領域の初期化を呼び、直後のヘッダーを `HL` に入れて `$02DE` へ跳ぶ。 |

**曲**の領域は `$C100`、`$C200`、`$C300`、`$C400` から各 `$20` バイト × 6チャンネル。`$031A` は `$C400`、`$C300`、`$C200`、`$C100` の順に先頭バイトを調べ、最初に0でない領域だけを更新する。初期化の入口は `$02B1`（`$C100`、26曲）、`$02BA`（`$C200`、コマンド `$30` と `$3B`）、`$02CC`（`$C400`、コマンド `$1D`、`$35`、`$37`）。`$C300` 用の `$02C3` はどこからも参照されない。

**効果音**のスタブが使うチャンネル領域とデータの先頭は次のとおり。

| コマンド | 領域 | データ | コマンド | 領域 | データ | コマンド | 領域 | データ |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `$01` | `$C560` | `$3D63` | `$0D` | `$C620` | `$44DE` | `$1A` | `$C640` | `$4DDB` |
| `$02` | `$C540` | `$3E30` | `$0E` | `$C540` | `$452A` | `$1B` | `$C640` | `$4ECA` |
| `$03` | `$C660` | `$3E9A` | `$0F` | `$C660` | `$45AF` | `$1E` | `$C540` | `$4F20` |
| `$04` | `$C500` | `$40A1` | `$10` | `$C560` | `$469E` | `$1F` | `$C620` | `$4F6B` |
| `$05` | `$C500` | `$40F2` | `$11` | `$C580` | `$4714` | `$20` | `$C620` | `$5200` |
| `$06` | `$C520` | `$411B` | `$12` | `$C620` | `$483A` | `$21` | `$C640` | `$533A` |
| `$07` | `$C780` | `$416F` | `$13` | `$C620` | `$4A41` | `$22` | `$C620` | `$549B` |
| `$08` | `$C560` | `$425E` | `$14` | `$C640` | `$4A81` | `$23` | `$C620` | `$54D8` |
| `$0B` | `$C620` | `$435E` | `$17` | `$C620` | `$4B10` | `$24` | `$C620` | `$55E9` |
| `$0C` | `$C620` | `$442E` | `$19` | `$C620` | `$4C10` | | | |

コマンドを送る場面は[コマンドと場面の対応](#コマンドと場面の対応)にまとめた。データ列の書式は未調査。

## コマンドと場面の対応

### 6809 側の送出

| 位置 | 内容 |
| --- | --- |
| fixed:`$776D` | `B` のコマンドを `$0140–$017F` のリングバッファに積む。`$52` と `$28` が両方0のときは積まない。`$7775` はこの判定を飛ばす入口。 |
| fixed:`$7788` | IRQ（`$65DC`）から呼ばれ、バッファから1個取り出して `$3A00` に書く。 |
| fixed:`$77BB` | `B` を積んだ後に `$FF` を積む。Z80 は前回と同じ値を無視するので、同じ効果音を続けて鳴らす経路はここを通る。 |
| fixed:`$779E–$78CB` | コマンドごとのスタブ。`LDB #コマンド` の後に `$776D` か `$77BB` へ跳ぶ。 |
| fixed:`$8DE7–$8E31` | ステージ曲の選択。`bank2:$4300` のページ表（1ページ4バイト）の3バイト目を読み、現在の曲 `$BD` より大きければ `$BD` に保存して送る。 |

下の表の根拠は次の3種類。**実測**は MAME でコマンドの要求を記録し、再現スクリプトが記録した出来事や入力とフレームを照合したもの。**コード**は呼び出し元の条件を逆アセンブルで読んだもの。**推定**は実測した時点や呼び出し元の位置からの推測で、音そのものは確認していない。

### 曲のコマンド

| コマンド | 場面 | 根拠 | 送出元 |
| --- | --- | --- | --- |
| `$2B` | 区間0・1のステージ曲。 | 実測、コード | ページ表。開始ページ `$000`、`$00E`。 |
| `$33` | 区間2・3のステージ曲。 | コード | ページ表。開始ページ `$040`、`$04E`。 |
| `$29` | 区間4・5のステージ曲。 | 実測、コード | ページ表。開始ページ `$05A`、`$0DD`。 |
| `$2A` | 区間6の曲。 | 実測、コード | ページ表。開始ページ `$15F`。 |
| `$2D` | 区間0・1のボスのページの曲。 | 実測、コード | ページ表の `$00C`、`$01A`、`$03A`。 |
| `$34` | 区間2・3のボスのページの曲。 | 実測、コード | ページ表の `$04C–$04D`、`$058–$059`、`$06C–$06D`。 |
| `$2E` | 区間4・5のボスのページの曲。 | 実測、コード | ページ表の `$09A–$09D`、`$0BA–$0BD`、`$0DA–$0DC`、`$11C–$11F`、`$13C–$13F`、`$15C–$15E`。 |
| `$30` | 開始のジングル。オープニングデモの最後、ミス後の再開、次の区間の開始で、ステージ曲の前に送る。 | 実測 | `$6FD9`、`$7A96` |
| `$31` | ミス。直前に `$3F` と `$00` を送る。 | 実測、コード | `$9A1C`（残機が残るとき）、`$EC81`（残り時間0）、`$F6E0` |
| `$2F` | ゲームオーバー。残機 `$60` が1のときにミスの代わりに送る。 | コード | `$9A17` |
| `$18` | 残り時間の警告。残り時間 `$AA` が15になったとき。 | コード | `$EC9A` |
| `$37` | 残機の増加。得点 `$64` が次の基準 `$68` を超えて残機 `$60` を増やした直後。 | コード | `$ED55` |
| `$3E` | 鍵の出現。ボスの消滅から3フレーム後、鍵の状態が1になったフレーム。 | 実測 | `$7409`、`$E521` |
| `$3B` | 鍵の取得後。鍵に触れてから51フレーム後。 | 実測 | `$7361` |
| `$35` | コイン投入。 | 推定 | `$67D7`、`$6834` |
| `$36` | 1P スタート。 | 推定 | `$6F98` |
| `$3C`、`$3D`、`$3A` | オープニングデモ。1P スタートの後、この順に送る。 | 実測 | `$79CC`、`$79DB`、`$79FD` |
| `$1D` | アイテムの取得。 | 推定 | アイテム処理の `$E70A`、`$E731` と `$E3A8` |
| `$26`、`$2C`、`$25`、`$27` | ネームエントリー。`bank3:$5C05` の表を順位の値で引く。 | コード | `bank3:$5BE1` |
| `$28` | ネームエントリーのカウンタが0になったとき。 | コード | `bank3:$5BF8` |
| `$1C`、`$32` | `$3F`、`$07`、`$08` の後、`$7F` が0なら `$1C`、0以外なら `$32`。場面は未特定。 | コード | `$DCBB–$DCCA` |
| `$38` | 未特定。 | — | `$7C64` |
| `$3F` | 曲の切り替え前に送る。ミス、ボス撃破後、再開の前など。 | 実測 | `$78C9` を呼ぶ各所 |
| `$39` | スタブ `$78AB` はあるが、呼び出しが見つからない。 | コード | — |

### 記録の方法

`tools/mame/log-revg-sound.lua` は `$776D` がバッファに書くたびに、フレーム、コマンド、スタックの上3語、区間 `$72` を `sound_request` 行に出力する。スタックの語から呼び出し元が分かる。`$3A00` への書き込みは `sound_latch` 行に出す。環境変数 `REVG_SOUND_SCENARIO` に既存の計測スクリプトを指定すると、その入力で進めながら記録する。

```powershell
$mameDir = "$env:USERPROFILE/tools/mame/mame0289"
$env:REVG_SOUND_SCENARIO = 'tools/mame/measure-revg-stage1-end.lua'
$env:REVG_STAGE1_END = 'key'
& "$mameDir/mame.exe" makaimurg -rompath reference -noreadconfig -video none -sound none -nothrottle -skip_gameinfo -autoboot_delay 0 -autoboot_script tools/mame/log-revg-sound.lua -cfg_directory build/revg-sound-log/cfg -nvram_directory build/revg-sound-log/nvram -seconds_to_run 372
Remove-Item Env:REVG_SOUND_SCENARIO, Env:REVG_STAGE1_END
```

上の例は区間0を鍵の取得まで進める試行で、`sound_request` は486行になる。コールドブートからの2回の実行で `sound_` 行が一致した。ほかに入力計測の `shot` と `jump`、水面への落下、ボス名簿の区間0〜6、縦スクロールの鍵（区間4）、武器の試行を同じ方法で記録した。

## コードとデータの範囲

リセットと IRQ から分岐をたどり、`RST $30` の分岐表4個（`$011F` が64語、`$05A3`、`$0759`、`$07D6` が各8語）と、`$074D` が戻り先として積む `$0738` を入口に加えた。

| 範囲 | 内容 |
| --- | --- |
| `$0000–$003B` | リセット、RST、IRQ の入口。 |
| `$00D4–$0BC8` | ドライバ本体。途中にデータの表（`$01EF–$02B0`、`$0577–$0586`）と分岐表を含む。 |
| `$0BC9–$0FD4` | データ。 |
| `$0FD5–$3D62` | 曲。30個の9バイトのスタブと、それぞれに続くデータ。 |
| `$3D63–$56C7` | 効果音のデータ。 |

命令は1,203個、2,725バイト。データは19,315バイト、分岐表は176バイト。次の3か所は ROM 内に参照がなく、未使用のコードとして扱った。

- `$01BB–$01EE`：`$C100` からの4領域を止め、両方の YM2203 に書き込むルーチン。
- `$02C3–$02CB`：`$C300` の領域を初期化する入口。
- `$059A`：単独の `RET`。

## 実行トレースとの照合

MAME のデバッガーで Z80 の実行トレースを取り、実行された命令のアドレスをすべて上のコード範囲と比べた。`$C800` の読み出しを差し替え、Z80 が最初にコマンドを読んだフレームから30フレームごとに `$00` から `$3F` までを順に与えた。

- 範囲外のアドレスの実行は0件。
- 1,203命令のうち1,151命令を実行した。
- 実行されなかった52命令は、トレース開始前に通過した `$0000`、上記の未使用の3か所、`$0024`、`$0466`、`$0475–$047B`、`$054D`、`$05C3–$05C9`、`$05D1–$05DE`、`$0746–$074A`、`$07AB–$07B8`。

各コマンドを30フレームで打ち切るので、曲や効果音の後半だけで使うデータ列の命令は通らない。コールドブートからの2回の実行でトレースファイルの SHA-1 が一致した。

## 再現手順

```powershell
$mameDir = "$env:USERPROFILE/tools/mame/mame0289"
python tools/mame/disassemble-revg.py --unidasm "$mameDir/unidasm.exe"
python tools/mame/trace-revg-sound.py --unidasm "$mameDir/unidasm.exe"
New-Item -ItemType Directory -Force build/revg-sound-trace | Out-Null
& "$mameDir/mame.exe" makaimurg -rompath reference -noreadconfig -video none -sound none -nothrottle -skip_gameinfo -debug -debugger none -autoboot_delay 0 -autoboot_script tools/mame/measure-revg-sound-coverage.lua -cfg_directory build/revg-sound-trace/cfg -nvram_directory build/revg-sound-trace/nvram -seconds_to_run 60
python tools/mame/trace-revg-sound.py --unidasm "$mameDir/unidasm.exe" --trace build/revg-sound-trace/z80.tr
```

`disassemble-revg.py` は `gg2.bin` を MAME の SHA-1 と照合し、`build/revg-disassembly/` に `sound.bin` と、先頭から順にデコードした `sound.asm` を出力する。`trace-revg-sound.py` は到達できる命令だけをデコードし、分岐先にラベルを付けた `sound-traced.asm` を同じ場所に出力する。到達しないバイトは `db`、分岐表は `dw` で並べる。

MAME の実行はトレースを `build/revg-sound-trace/z80.tr`（約60 MB）に書き出し、最後のコマンドの後に終了する。`--trace` を付けた実行は、範囲外の実行があれば該当アドレスを表示して終了コード1を返す。
